# Влияние chain-of-thought на качество ответов малых LLM

## Постановка задачи

## Гипотезы
1) У самых малых моделей CoT помогает слабее, чем у больших, а иногда ухудшает ответ
2) На GSM8K выигрыш от CoT больше, чем на ARC
3) Few-shot с тремя примерами (GSM8K: решения из обучающей части набора; ARC: самостоятельно написанные короткие рассуждения) даёт такую же точность, как cot без примеров, но с меньшим числом сгенерированных токенов.
4) Выигрыш от CoT растёт с числом шагов в эталонном решении
